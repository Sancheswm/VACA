# Experimentos

Esta pasta versiona apenas descrições e manifestos pequenos de experimentos. Dados, checkpoints e outputs pesados permanecem no Drive.

Cada experimento deve registrar:

- objetivo e hipótese;
- commit Git;
- configuração usada;
- fonte e versão dos dados;
- estratégia de split;
- seed;
- modelo/checkpoint;
- métricas planejadas;
- métricas obtidas;
- limitações e falhas;
- localização dos artefatos no `VACA_DATA`.

Nome recomendado:

`YYYYMMDD__task__model__dataset.md`

Resultados sem manifesto não devem ser promovidos a baseline oficial.
